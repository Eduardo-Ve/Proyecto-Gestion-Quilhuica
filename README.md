## Instalación local
```git clone https://github.com/Eduardo-Ve/Proyecto-Gestion-Quilhuica```

```cd Proyecto-Gestion-Quilhuica```

```pip install -r requirements.txt```

```python manage.py migrate```

```python manage.py runserver ```
